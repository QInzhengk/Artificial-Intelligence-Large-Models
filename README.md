## :watermelon: 简介

> :corn: 本项目专注于**人工智能大模型**及其在**工业领域**的应用，尤其是**功率预测**（风电/光伏/负荷预测）和 **AI+ 工业制造**（质量检测、设备预测性维护、智能排产等）。整理了大量学习笔记、论文、代码和实战项目（**持续更新中......**）。
>
> :tomato: 作者具有扎实的数理基础（高考数学144，全国大学生数学竞赛一等奖），并在华为杯中国研究生数学建模竞赛中获一等奖，目前深耕AI大模型与工业智能方向。
>
> :eggplant: 将此项目开源，帮助对**大模型、功率预测、工业AI**感兴趣的初学者和从业者快速入门。如果觉得有用，请点个 star ⭐ 吧！感谢！！
>
> :sweet_potato: 欢迎 PR 和 issue，一起构建工业AI知识库。
